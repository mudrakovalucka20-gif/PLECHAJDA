# PLECHAJDA — náhled webu

Statický náhled webu Plechajda.

## Struktura

- `index.html` — celá stránka (HTML + CSS + JS v jednom souboru)
- `images/` — obrázky vytažené z původního souboru

Původní podklad byl jeden HTML soubor o velikosti 3,14 MB s obrázky
zapečenými jako base64. Obrázky jsou nyní samostatné soubory, takže
HTML má 50 KB a jdou v něm sledovat skutečné změny.

## Náhled

Otevři `index.html` v prohlížeči, nebo zapni GitHub Pages
(Settings → Pages → Deploy from a branch → main / root).
